\# lab-01



\## Objetivo

Repositório de aprendizado prático de desenvolvimento web,

criado durante o Playbook de Desenvolvimento da Gabillaud.



\## Stack

\- Python 3.14

\- FastAPI

\- Uvicorn

\- JavaScript (Vanilla)

\- HTML/CSS

\- Git



\## Como executar

1\. Ative o ambiente virtual:

&#x20;  .venv\\Scripts\\activate



2\. Suba a API:

&#x20;  uvicorn main:app --reload



3\. Abra o arquivo clientes.html no navegador.
